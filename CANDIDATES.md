The live X Bookmarks tab was also screened, including a first batch of 37 visible posts and a second batch of 84 (the boundary can overlap). Two relevant public posts described OpenJarvis running Mini and the registry challenge. Neither supplied another pinned M1 verifier/drafter pair. [OpenJarvis demonstration](https://x.com/JonSaadFalcon/status/2123939021646942346), [registry challenge](https://x.com/0xSero/status/2123927616105378234).

The original Mini snapshot at ed40e7da625f594fc9c4990f5f66be24873c22d7 includes the target safetensors, the 635 MB mtp.safetensors and its tokenizer. The experimental TensorFold revision built locally with Zig 0.17 and pkgconf. The NetProjects MLX-VLM fork installed as version 0.8.0+inkling2mini.2. Both use this same original snapshot for their first off/on screens.

oMLX used the isolated 0.8.2 wheel with MLX and mlx-metal 0.32.4, mlx-lm 0.32.3.dev8+g0d4d3d04f, mlx-vlm 0.7.11, Transformers 5.22.2 and tokenizers 0.23.3 from the existing application runtime. The fixed-depth loader reported depth 3, adaptive false. The adaptive loader reported depth 6, adaptive true. Both logged target layers 5, 23, 41 and 48. On the first 256-ID native fixed-depth probe, oMLX counted 151 accepted of 225 proposed in 103 cycles. The backbone took 10,247.5 ms, the draft head 561.5 ms, and sampling and cache work another 60.8 ms. The native counters, including each emission category, are in raw/oq4-fixed3/mtp.json.

The TensorFold native server ran the original target and its own DSpark implementation. On the same 34-input/256-output request it measured 8.03 tok/s with and without drafting. With drafting enabled it verified 111 of 186 proposals in 145 rounds. The advertised native model geometry was 48 logical layers over 24 physical layers. Both endpoints put Inkling's literal think and invocation markers in visible output on both Pi fixtures. Pi executed zero tools. The build also warned that its optional structured-output grammar library was absent. These Pi requests used auto tool selection, so that warning alone does not establish the cause of the leaked markers.

The NetProjects MLX-VLM implementation accepted the original mixed-precision snapshot on the M1 Max. Its HTTP listener started before the background loader was ready, returning 503 to the first probe. Its health endpoint exposes model_ready, which the guard now checks before timing. With draft off the model produced 16.93 client-observed tok/s on a 34-input/256-output probe and passed both Pi tasks. The primary task delivered 15.36 server-timed tok/s in 42.45 seconds. The follow-up quantization screen uses NetProjects' affine 4-bit target d90008cbfa520bc53d75eeafbecb10f266fdf5fc with its own matched drafter.

The MLX-VLM affine target with its native RAM prefix cache (64 blocks of 64) cut the primary task to 23.72 s with draft off and 19.78 s with draft on. Measured Pi decode was 18.40 and 25.22 tok/s respectively. The drafted held-out fixture finished in 15.38 s using three tools, compared with four on the oMLX held-out run. This is a single screening observation on a different task trajectory.
